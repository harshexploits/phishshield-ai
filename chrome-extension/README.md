# 🧩 PhishShield AI - Chrome Extension

This Chrome Extension brings **PhishShield AI** threat intelligence right into your browser toolbar, allowing instant 1-click scanning of active websites and suspicious links.

---

## 🚀 How to Install in Chrome (Developer Mode)

1. Open Google Chrome and go to `chrome://extensions/`.
2. Enable **"Developer mode"** (toggle in the top-right corner).
3. Click **"Load unpacked"** (top-left button).
4. Select the directory: `D:\Github\phishshield-ai\chrome-extension`.
5. The **PhishShield AI** shield icon will appear in your Chrome extensions bar!

---

## 🌟 Features
- **1-Click Active Tab Inspection**: Instant threat check of current webpage URL.
- **Credential Harvesting Alert**: Detects suspicious keywords (`paypal-verify`, `account-login`, etc.) and burner TLDs (`.xyz`, `.top`).
- **Cosmic Purple 3D UI**: Matches the PhishShield AI web application theme.
